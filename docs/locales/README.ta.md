Softfold உங்கள் MacBook-ன் கீலுடன் இயைந்து இயங்குகிறது. திரையை நீங்கள் கீழே இறக்கும் போது, உங்கள் நேரலை டெஸ்க்டாப் மெல்ல பின்நோக்கி சாய்ந்து, மேலிருந்து கீழ்நோக்கி மங்கலாகி, இருண்ட விளிம்புகளில் கரைகிறது. திரையை மீண்டும் உயர்த்தினால், நீங்கள் விட்டுச்சென்ற இடத்திலேயே அனைத்தும் மிகத் துல்லியமாக மீண்டு வரும்.

## பதிவிறக்கம்

[Softfold.dmg-ஐப் பதிவிறக்குங்கள்](https://github.com/ReffWu/softfold/releases/latest/download/Softfold.dmg), கோப்பைத் திறந்து Softfold-ஐ Applications கோப்புறைக்கு இழுக்கவும். செயலி Developer ID கொண்டு கையொப்பமிடப்பட்டு Apple-ஆல் சரிபார்க்கப்பட்டுள்ளது, எனவே பிற Mac செயலிகளைப் போல பாதுகாப்பாகத் திறக்கும்.

முதல் முறை திறக்கும் போது கணினி அமைப்புகளில் «திரைப்பதிவு» அனுமதியை வழங்கவும், macOS கேட்டால் செயலியை மீண்டும் திறந்து இயக்கவும். இனி உங்கள் Mac தொடங்கும் போதே இது தானாக இயங்கத் தொடங்கும்.

முதலில் இயக்கும் போது திரையின் தற்போதைய கோணம் தொடக்கக் கோணமாகக் கொள்ளப்படும். பின்னர் மாற்ற விரும்பினால், திரையை விருப்பமான கோணத்தில் வைத்து **தற்போதைய கோணத்தைப் பயன்படுத்து** என்பதை அழுத்தவும். <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>H</kbd> குறுக்குவழி மூலம் எந்த நேரத்திலும் விளைவை இயக்கலாம் அல்லது நிறுத்தலாம்.

## ஆதரிக்கப்படும் MacBook மாடல்கள்

Softfold இயங்க Apple 2019 முதல் இணைத்துள்ள மூடி கோண சென்சார் (Apple Silicon சாதனங்களில் சென்சார் இணைச் செயலி மூலம் கிடைக்கிறது) மற்றும் macOS 14 அல்லது புதிய பதிப்பு தேவை. உங்கள் Mac-ல் சென்சார் இல்லையென்றால் Softfold அதை உங்களுக்குத் தெரிவிக்கும்.

| நிலை | மாடல்கள் |
| --- | --- |
| இயங்குகிறது, பயனர்களால் உறுதி செய்யப்பட்டது | M1 Pro அல்லது M1 Max (2021), M2 Max (2023), M3 Pro அல்லது M3 Max (2023), M4 Pro அல்லது M4 Max (2024) கொண்ட 14" மற்றும் 16" MacBook Pro. M4 (2025) அல்லது M5 கொண்ட MacBook Air |
| சென்சார் உள்ளது, இன்னும் உறுதி செய்யப்படவில்லை | M3, M4 அல்லது M5 கொண்ட 14" MacBook Pro. M5 Pro அல்லது M5 Max கொண்ட 14" மற்றும் 16" MacBook Pro. M2 அல்லது M3 கொண்ட MacBook Air |
| ஆதரிக்கப்படவில்லை | M1 கொண்ட MacBook Air, அனைத்து 13" MacBook Pro (Intel, M1 மற்றும் M2), Intel அடிப்படையிலான MacBook Pro, 12" MacBook, MacBook Neo, டெஸ்க்டாப் Mac |

2019-ன் 16-இன்ச் MacBook Pro-விலும் இந்த சென்சார் உள்ளது, ஆனால் வெளியிடப்பட்ட செயலி பிரத்தியேகமாக Apple Silicon-க்காக தொகுக்கப்பட்டுள்ளது.

சந்தேகமா? Terminal-ல் இந்த கட்டளையை இயக்கவும். «las» என முடியும் வரி உங்கள் Mac-ன் மூடி சென்சாரை Softfold படிக்க முடியும் என்பதைக் குறிக்கிறது:

```sh
hidutil list --matching '{"VendorID":0x5ac,"PrimaryUsagePage":32,"PrimaryUsage":138}'
```

நடுவரிசை மாடலில் முயற்சித்தீர்களா? [உங்கள் அனுபவத்தைப் பகிருங்கள்](https://github.com/ReffWu/softfold/issues).

## இது எவ்வாறு செயல்படுகிறது

Softfold மூடியின் கோணத்தை IOKit HID மூலம் ஒரு பாகையின் நூறில் ஒரு பங்கு துல்லியத்துடன் படிக்கிறது. முக்கியமான தணிப்பு வடிகட்டி (critically damped filter) அளவீடுகளை இயற்கையான, தொடர்ச்சியான அசைவாக மாற்றுகிறது. மெதுவான சாய்வு - மென்மையான மடிப்பு. வேகமான அசைவு - உடனடி எதிர்வினை. பாதி வழியில் ஒரு வினாடி நிறுத்தினால், டெஸ்க்டாப் மீண்டும் தெளிவு பெறும், மீண்டும் மூடும்போது மடியத் தொடங்கும்.

ScreenCaptureKit நேரலை டெஸ்க்டாப்பை வழங்குகிறது மற்றும் Metal இன்ஜின் 60 fps வேகத்தில் காட்சியை வரைகிறது. திரைப்பிடிப்பு மூடி அசையும் போது அல்லது மடிந்திருக்கும் போது மட்டுமே இயங்கும், மீண்டும் முழுமையாக திறந்த சில வினாடிகளில் நின்றுவிடும். படங்கள் எப்போதும் Mac-ன் RAM நினைவகத்தில் மட்டுமே இருக்கும், எங்கும் சேமிக்கப்படாது. பயன்பாட்டை மதிப்பிட Softfold ஒரு நாளைக்கு ஒருமுறை அநாமதேய சமிக்ஞையை அனுப்புகிறது. தனிப்பட்ட தரவு எதுவும் சேகரிக்கப்படாது.

இயக்கத்தின் முழுமையான வடிவமைப்பு [MOTION.md](../../MOTION.md)-ல் உள்ளது.

## மூலக் குறியீட்டிலிருந்து கட்டமைத்தல்

Xcode-ஐ நிறுவி இயக்கவும்:

```sh
git clone https://github.com/ReffWu/softfold.git
cd softfold
make build
open build/Softfold.app
```

வளர்ச்சிச் சோதனைகள் [CHECKS.md](../../CHECKS.md)-லும், கையொப்பமிடப்பட்ட வெளியீடுகள் [RELEASE.md](../../RELEASE.md)-லும் விவரிக்கப்பட்டுள்ளன.
