Softfold เคลื่อนไหวตามบานพับของ MacBook อย่างเป็นธรรมชาติ เมื่อคุณค่อยๆ พับหน้าจอลง เดสก์ท็อปที่กำลังทำงานอยู่จะเอียงไปข้างหลังพร้อมกัน ค่อยๆ เบลอจากด้านบนลงมาและกลมกลืนไปกับขอบมืดด้านข้าง เมื่อเปิดหน้าจอขึ้นมาใหม่ ทุกสิ่งจะกลับมาคมชัดทันที ณ จุดเดิมที่คุณปล่อยไว้

## ดาวน์โหลด

[ดาวน์โหลด Softfold.dmg](https://github.com/ReffWu/softfold/releases/latest/download/Softfold.dmg) เปิดไฟล์และลาก Softfold ไปยังโฟลเดอร์ Applications แอปนี้ได้รับการลงนามด้วย Developer ID และผ่านการตรวจสอบรับรอง (notarized) โดย Apple จึงเปิดใช้งานได้อย่างปลอดภัยเช่นเดียวกับแอป Mac ทั่วไป

เมื่อเปิดใช้งานครั้งแรก ให้ไปที่ «การตั้งค่าระบบ» เพื่ออนุญาต «การบันทึกหน้าจอ» เปิด Softfold ใหม่อีกครั้งหากระบบร้องขอ แล้วเปิดใช้งาน หลังจากนั้นแอปจะเริ่มทำงานโดยอัตโนมัติพร้อมกับการเปิดเครื่อง Mac ของคุณ

เมื่อเปิดใช้งานครั้งแรก Softfold จะบันทึกมุมปัจจุบันของหน้าจอเป็นมุมเปิดเริ่มต้น หากต้องการเปลี่ยนในภายหลัง เพียงปรับหน้าจอให้อยู่ในมุมที่ต้องการแล้วคลิก **ใช้มุมปัจจุบัน** สามารถใช้ปุ่มลัด <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>H</kbd> เพื่อเปิดหรือปิดเอฟเฟกต์ได้ทุกเมื่อ

## รุ่น MacBook ที่รองรับ

Softfold ต้องใช้เซ็นเซอร์วัดมุมฝาพับที่ Apple เริ่มติดตั้งมาตั้งแต่ปี 2019 (ทำงานบน Apple Silicon ผ่านตัวประมวลผลร่วมของเซ็นเซอร์) และต้องใช้ macOS 14 ขึ้นไป หาก Mac ของคุณไม่มีเซ็นเซอร์นี้ Softfold จะแจ้งเตือนให้คุณทราบทันที

| สถานะ | รุ่น |
| --- | --- |
| ใช้งานได้ ได้รับการยืนยันจากผู้ใช้ | MacBook Pro 14" และ 16" ที่ใช้ M1 Pro หรือ M1 Max (2021), M2 Max (2023), M3 Pro หรือ M3 Max (2023), M4 Pro หรือ M4 Max (2024) รวมถึง MacBook Air ที่ใช้ M4 (2025) หรือ M5 |
| มีเซ็นเซอร์ ยังไม่ได้รับการยืนยัน | MacBook Pro 14" ที่ใช้ M3, M4 หรือ M5 รวมถึง MacBook Pro 14" และ 16" ที่ใช้ M5 Pro หรือ M5 Max และ MacBook Air ที่ใช้ M2 หรือ M3 |
| ไม่รองรับ | MacBook Air ที่ใช้ M1, MacBook Pro 13" ทุกรุ่น (Intel, M1 และ M2), MacBook Pro ที่ใช้ชิป Intel, MacBook 12", MacBook Neo, Mac แบบตั้งโต๊ะ |

MacBook Pro รุ่น 16 นิ้วปี 2019 มีเซ็นเซอร์นี้เช่นกัน แต่แอปที่เผยแพร่นี้สร้างขึ้นสำหรับสถาปัตยกรรม Apple Silicon โดยเฉพาะ

ไม่แน่ใจใช่หรือไม่? ให้รันคำสั่งนี้ใน Terminal บรรทัดที่ลงท้ายด้วย «las» หมายความว่า Softfold สามารถตรวจจับเซ็นเซอร์ฝาพับของคุณได้:

```sh
hidutil list --matching '{"VendorID":0x5ac,"PrimaryUsagePage":32,"PrimaryUsage":138}'
```

ได้ลองใช้กับรุ่นในแถวกลางแล้วหรือยัง? [แชร์ความคิดเห็นกับเราได้ที่นี่](https://github.com/ReffWu/softfold/issues)

## กลไกการทำงาน

Softfold อ่านค่ามุมฝาพับผ่าน IOKit HID ด้วยความแม่นยำระดับหนึ่งในร้อยขององศา โดยปรับให้เข้ากับจังหวะของเซ็นเซอร์โดยตรง ตัวกรองแบบลดทอนวิกฤต (critically damped filter) จะแปลงข้อมูลให้เป็นการเคลื่อนไหวที่ลื่นไหลและเป็นธรรมชาติ การเอียงช้าจะพับเก็บอย่างนุ่มนวล การเอียงเร็วจะตอบสนองทันที หากคุณหยุดพักชั่วขณะระหว่างพับ เดสก์ท็อปจะค่อยๆ กลับมาชัดเจน และพับต่อทันทีที่คุณพับฝาลงต่อ

ScreenCaptureKit จะแสดงภาพเดสก์ท็อปแบบเรียลไทม์ และ Metal จะเรนเดอร์มุมมองมิติและความเบลอที่อัตรา 60 fps การจับภาพจะทำงานเฉพาะตอนที่ฝาพับกำลังเคลื่อนไหวหรือพับอยู่เท่านั้น และจะหยุดลงไม่กี่วินาทีหลังจากเปิดจอขึ้นมาใหม่ ภาพทั้งหมดจะอยู่ในหน่วยความจำ RAM เท่านั้น ไม่มีการบันทึกลงดิสก์หรือส่งออกไปยังเครือข่าย วันละครั้ง Softfold จะส่งสัญญาณสถิติแบบไม่ระบุตัวตนเพื่อประเมินจำนวนเครื่องที่ใช้งาน ไม่มีการรวบรวมข้อมูลส่วนบุคคลใดๆ ทั้งสิ้น

รายละเอียดการออกแบบการเคลื่อนไหวทั้งหมดอยู่ใน [MOTION.md](../../MOTION.md)

## สร้างจากซอร์สโค้ด

ติดตั้ง Xcode แล้วรันคำสั่ง:

```sh
git clone https://github.com/ReffWu/softfold.git
cd softfold
make build
open build/Softfold.app
```

ขั้นตอนการตรวจสอบระหว่างพัฒนาอยู่ใน [CHECKS.md](../../CHECKS.md) และเวอร์ชันพร้อมลงนามอยู่ใน [RELEASE.md](../../RELEASE.md)
